# Saint Harness 0.1.8

首个提供完整下载包的版本，包含此前 0.1.0–0.1.8 的桌面功能。

## 下载与启动

下载 **Saint-Harness-0.1.8-x64.zip**，完整解压到可写目录，双击 **Saint Harness.exe**。已包含 Electron、Node 和 Pi 1.5.1，无需另装 Node 或 Pi。不要只取出一个 exe 运行。

适用 Windows 10/11 x64。首次启动选择自己的项目目录、配置自己的模型 API。GitHub 自动附带的 Source code 是源码，不是可直接运行的软件。

**hanasakis-saint-harness-0.1.8.tgz** 是 GitHub Packages 的同版本 npm 分发包，内含相同 Windows ZIP；适合使用包仓库的开发者。一般用户直接下载上面的 ZIP。

## 这个版本包含什么

- Saint 黑白桌面界面、玻璃棱镜品牌形象，连接 Anthropic、OpenAI、DeepSeek 及兼容服务，支持测试连接。
- 优先使用内置 Pi，支持检测、连接本地引擎、同目录更新及回退。
- 并行会话、智能标题、Token 和缓存命中率、准确的小百分比上下文显示。
- 项目与会话右键菜单、跨项目迁移、本机会话链接、归档恢复与永久删除。
- 任意文件拖放，剪贴板图片 / 文件 / 文字粘贴，统一主题菜单与权限确认。
- 只引用选中文字的 Add to chat / Ask in side chat；引用标签悬停展开 Selected text。
- 持久 Side Chat、左侧列表、可拖动分隔线、独立回复 / 审批 / 停止、重启恢复与用户管理归档删除。

## 验证与已知限制

发布流程先执行核心测试、构建及打包版桌面测试，再发布下载资源和 npm 包。模型交互测试使用真实 Pi 与本地可控服务，没有使用真实商业模型凭据；具体记录见仓库 VALIDATION.md 与对应 Actions 运行附件。

当前为未签名的开发版，Windows 可能提示未知发布者；请核对下载来源后自行决定是否运行。未提供 macOS / Linux 成品、签名安装器或 Saint 桌面自动更新。Pi 自身可独立更新。

升级前关闭旧应用并保留旧目录作为备份。项目、聊天和密钥存放在 **%APPDATA%/Saint Harness**，不要删除该目录；下载包不包含作者的聊天记录或密钥。
