# Saint Harness 0.1.9

根据界面反馈改进模型管理、技能添加与浮层交互，延续 Saint 黑白圆角与磨砂浮层主题。

## 本版变化

- 点击输入框、聊天区域或侧栏即可关闭外部浮层，主对话和 Side Chat 均支持，Esc 也可关闭。
- 模型管理新增「添加模型」与已保存模型列表，可手动添加多个 OpenAI 兼容模型。连接、密钥、测试、编辑和删除彼此独立，兼容原有配置。
- 导入技能不再要求文件名为 SKILL.md，任意名称的 Markdown 技能均可选择；保留 Pi 内容校验与 128 KB 大小限制，加载失败会撤销此次添加。
- 主对话和 Side Chat 输入 `/` 可搜索技能，方向键选择、Enter / Tab 添加、Esc 收起；添加后显示标签并保留原有草稿，发送时才附带技能内容。
- 个人信息区与独立设置按钮的布局调整已记录到后续计划，本版不改动该区域。

## 下载

Windows 10/11 x64 用户下载 **Saint-Harness-0.1.9-x64.zip**，完整解压后运行 **Saint Harness.exe**。包含 Electron、Node 与 Pi 1.5.1。升级前关闭旧应用，保留旧目录及 `%APPDATA%/Saint Harness` 中的数据。

**hanasakis-saint-harness-0.1.9.tgz** 是同版本 GitHub Packages 分发包，内含相同 Windows ZIP。一般用户直接下载 ZIP 即可。

## 验证范围

发布流程执行核心测试、构建，以及打包版桌面、并行会话、Side Chat、剪贴板和新增模型/技能交互测试。交互测试连接真实 Pi 与本地可控模型服务，验证独立密钥、模型切换、技能实际发送和重启恢复；未调用商业模型服务。

仍为未签名 Windows 开发版，尚无 Saint 桌面自动升级。Pi 引擎沿用现有独立更新机制；下载包不含作者的项目、聊天或密钥。
